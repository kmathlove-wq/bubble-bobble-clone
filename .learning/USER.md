# User Profile

- 사용자는 초등학생, 바이브코딩 애호가. 컴퓨터 비전문가 — 전문용어는 쉬운 말로 풀어서 설명.
- 엔트리(블록 코딩) 경험 많음. 이 프로젝트의 원본 아이디어도 사용자가 만든 엔트리 작품
  "버블보블"(playentry.org/project/6652ffa6e1dc323e5e9c45ad, 2024-05, 김민결15). 그 작품은 간단하고 어려운 편.
- 원작 게임(1986 아케이드 버블보블)에 최대한 가깝게 만들고 싶어 함. 그림·효과음도 비슷하게.
- 저작권: 원작(타이토)의 진짜 그림·음원은 사용 금지. 사용자 본인이 엔트리 수업에서 만든 그림과
  배경음악.mp3는 사용 OK. 효과음은 새로 생성. (사용자가 준 khinsider 음원 링크 = 원작 립이라 사용 불가로 합의함.)
- 완성 후 GitHub 공개 저장소 + GitHub Pages 배포 원함. `gh` 설치돼 있음. 커스텀 도메인은 나중에 사용자가 알려줌.
- 게임을 직접 플레이하고 스크린샷으로 피드백 주는 스타일(점프맵 프로젝트에서 확인).
